# 🎵 RitmoLatam Analytics: Explorador de Tendencias Musicales en Latinoamérica 💃🕺

[![Python](https://img.shields.io/badge/Python-3.9%2B-3776AB?style=for-the-badge&logo=python&logoColor=white)](https://www.python.org/)
[![Streamlit](https://img.shields.io/badge/Streamlit-1.28%2B-FF4B4B?style=for-the-badge&logo=streamlit&logoColor=white)](https://streamlit.io/)
[![Plotly](https://img.shields.io/badge/Plotly-Express-3F4F75?style=for-the-badge&logo=plotly&logoColor=white)](https://plotly.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

Un panel de control interactivo diseñado para explorar, visualizar y analizar la evolución de los **géneros musicales en Latinoamérica durante los últimos 20 años**. La aplicación permite identificar patrones de consumo, la penetración de mercado por país y la relación entre métricas de *streaming*, éxitos en *charts* e hitos como premios Grammy Latinos o giras internacionales.

> *"La música latinoamericana no solo se escucha: se transforma a ritmo constante. Esta herramienta convierte datos complejos del panorama musical en insights visuales accionables."*

---

## ✨ Características Principales

* **🎛️ Filtrado Dinámico Multi-variable:** Segmentación en tiempo real por género musical, país de origen y reconocimiento académico (Grammy Latino).
* **📊 Visualizaciones Interactivas con Plotly Express:**
  * **Top Oyentes Mensuales:** Gráfico de barras horizontales detallado por artista y género.
  * **Distribución Geográfica:** Gráfico circular de dona para analizar la cuota de producción por país.
  * **Análisis de Éxito en Charts:** Histograma interactivo de distribución de canciones en el Top 10 cruzado con giras activas.
* **👀 Explorador de Datos Integrado:** Vista previa interactiva y limpia del *dataset* filtrado con métricas clave.

## 🛠️ Tecnologías Utilizadas

Este proyecto fue desarrollado utilizando el *stack* moderno de ciencias de datos y analítica web en Python:

* 🐍 **[Python 3.9+](https://www.python.org/):** Lenguaje principal para el procesamiento de datos y la lógica de negocio.
* 🐼 **[Pandas](https://pandas.pydata.org/):** Manipulación, limpieza y filtrado eficiente de estructuras de datos tabulares.
* 📊 **[Plotly Express](https://plotly.com/python/plotly-express/):** Creación de gráficos interactivos de alta calidad visual.
* 🚀 **[Streamlit](https://streamlit.io/):** Framework para convertir scripts de Python en aplicaciones web analíticas interactivas de manera ágil.
